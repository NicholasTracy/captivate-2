## What's new in Captivate 2 1.3.0

This release adds show control, a performance bank, projection keystone output, and a VJ-ready visualizer with projectM presets.

### Show control

- **Performance bank** — Pads and sliders can drive more than one scene route, and can send MIDI and OSC.
- **Connections** — MIDI, OSC, Ableton Link tempo roles, and Pro DJ Link BPM follow.
- **One-shots** — Fire a DMX cue without leaving it running.

### Visuals

- **VJ looks** — Add the starter looks from the visual scene list. Each one is a normal scene you can edit.
- **Generators** — Living fractal, honeycomb, and a body of water that sloshes and ripples on the beat.
- **projectM** — The preset pack is part of the install. If a copy is missing, Captivate installs it into that app’s settings the first time a projectM layer looks for presets. Runtime Default opens the first preset.

### Projection

- **Keystone** — The preview and the point map share one homography.
- **Helios** — One DAC traces the visualizer through that keystone.

### Installing

Download the installer for your operating system below. You can install over Captivate 2 1.2.1; projects and settings are kept.

#### macOS install

Captivate 2 is not Apple-notarized. Download the **architecture-specific** DMG:

- **Apple Silicon (M1–M4):** `Captivate.2-1.3.0-arm64.dmg`
- **Intel Mac:** `Captivate.2-1.3.0-x64.dmg`

Check **About This Mac** → **Chip** (Apple M…) vs **Processor** (Intel). Do not use a generic `.dmg` without `-arm64` or `-x64` if both are listed.

First launch: drag to **Applications**, then **right-click → Open** and confirm. Full steps: [docs/MACOS-INSTALL.md](https://github.com/NicholasTracy/captivate-2/blob/Main/docs/MACOS-INSTALL.md).
